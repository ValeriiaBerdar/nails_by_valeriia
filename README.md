# Nails by Valeriia

Веб-додаток для представлення послуг майстра манікюру та онлайн-запису клієнтів.

## Основні можливості

- перегляд послуг;
- галерея робіт;
- інформація про додаткові послуги;
- форма онлайн-запису;
- контактна інформація.

## Стек проєкту

- React
- Vite
- JavaScript
- HTML/CSS
- ESLint
- Prettier
- Husky (Git Hooks)
- Cypress (Component та E2E testing)

## Структура

Інтерфейс розділений на окремі React-компоненти: Header, Hero, Services, AdditionalServices, Gallery, BookingForm, Contacts та Footer.

Проєкт створено в межах лабораторної роботи.
